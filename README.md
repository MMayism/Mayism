# MAYISM V11 — Artist Exhibition

A full visual-direction redesign for MAYISM / Pheemwara Choymuang. The site is intentionally art-directed rather than template-like: editorial typography, asymmetrical exhibition layouts, sketchbook treatment, architecture archive, studio notes, layered pink paper, subtle motion, reveal transitions, progress line and interactive lightbox.

## Deploy
Upload the contents of this folder to the root of the GitHub Pages repository.

## Important
All existing MAYISM artwork/assets are preserved. The redesign changes presentation, layout, typography and motion—not the artwork itself.
